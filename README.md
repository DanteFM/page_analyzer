# Page Analyzer (Анализатор страниц)

Сервис для проверки сайтов: принимает URL, безопасно загружает страницу, парсит SEO-теги (`title`, `h1`, `description` и др.) и хранит историю проверок для каждого посетителя.

**Демо:** https://page-analyzer-ten.vercel.app

## Стек

- **Next.js 16** (App Router) + TypeScript
- **Ant Design 6** — UI-компоненты
- **Drizzle ORM** + **Postgres (Neon)** — хранение данных
- **cheerio** — парсинг HTML
- **Vitest** — юнит-тесты
- Деплой — **Vercel**

## Архитектура

Проверка выполняется **синхронно** в рамках одного запроса: пользователь отправляет URL → сервер загружает страницу → парсит → сохраняет результат → возвращает на клиент. Очередей и фоновых воркеров нет — для объёма и таймаутов пет-проекта это осознанное упрощение.

История проверок привязана не к аккаунту, а к анонимной сессии: при первом заходе выдаётся cookie с случайным идентификатором, и все проверки посетителя привязываются к нему. Регистрации нет.

### Защита от SSRF

Проект ходит по произвольным URL, которые вводит любой посетитель, — это создаёт риск SSRF (запрос на внутренние адреса вроде `localhost` или облачных метаданных). Защита реализована в функции `safeFetch`:

- резолвинг DNS и проверка IP на приватные/служебные диапазоны **до** запроса и на каждом редиректе;
- запрет автоматических редиректов (`redirect: "manual"`) — иначе проверка нового хоста произойдёт слишком поздно;
- таймаут запроса, лимит размера тела ответа, проверка `Content-Type`.

### Защита от перегрузки

- Лимит проверок в час по IP-адресу (`x-forwarded-for`).
- Cooldown 30 секунд между повторными проверками одного и того же сайта — при частом повторе возвращается последний сохранённый результат без нового сетевого запроса.

## Известные ограничения

- Защита от SSRF не закрывает DNS rebinding (домен резолвится в публичный IP на момент проверки, а к моменту соединения — в приватный).
- `x-forwarded-for` можно подделать, если запрос идёт не через Vercel (сам Vercel этот заголовок не даёт подменить).
- История проверок привязана к cookie: её очистка или заход с другого устройства сбрасывают список сайтов.
- JS-страницы (SPA) не рендерятся — анализируется только исходный HTML.
